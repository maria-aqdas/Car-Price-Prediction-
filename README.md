# 🚗 Car Price Prediction Model 📈

An end-to-end Machine Learning project designed to analyze automotive market trends and accurately predict the selling prices of used cars based on historical vehicle features. 🚘✨

---

## 📌 Project Overview 🎯

Predicting the market value of used vehicles is a vital challenge for dealerships, individual buyers, and sellers. This project provides a complete data science pipeline to:
* 🧹 **Clean & Preprocess** raw automotive tabular data.
* 📊 **Perform Exploratory Data Analysis (EDA)** to uncover key pricing trends and depreciation factors.
* 🛠️ **Engineer & Encode** features like brand, fuel type, transmission, and vehicle age.
* 🤖 **Train & Evaluate** regression models to achieve accurate price estimates.

## 🔄 Machine Learning Workflow ⚙️

1. **Data Cleaning & Preprocessing** 🧼
* Handling missing values and removing anomalous data points.
* Parsing and standardizing numerical units (e.g., mileage, engine size).


2. **Exploratory Data Analysis (EDA)** 🔍
* Generating correlation heatmaps to spot high-impact price drivers.
* Analyzing price distributions across brands, transmission types, and fuel sources.


3. **Feature Engineering & Transformation** 🔧
* Encoding categorical variables using One-Hot / Ordinal Encoding.
* Scaling continuous features using standard scaling techniques.


4. **Model Training & Evaluation** 🏆
* Training baseline and ensemble regression algorithms (e.g., Linear Regression, Random Forest).
* Measuring performance using regression metrics:
* 📐 **$R^2$ Score** (Coefficient of Determination)
* 🎯 **MAE** (Mean Absolute Error)
* 📏 **RMSE** (Root Mean Squared Error)
